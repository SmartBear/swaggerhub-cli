# Agent notes

This repo is the Swagger CLI (`swaggerhub`), an oclif app. Commands live in `src/commands`, shared logic in `src/support`, tests in `test`.

- Tests: `npm test`. Lint: `npm run lint` (see `package.json` scripts).
- README command docs are generated from oclif metadata; do not hand-edit the commands section.
- To *use* the CLI as an agent, see `skills/swaggerhub-cli/SKILL.md`.
